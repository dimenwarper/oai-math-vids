# Explainers for the OpenAI math catalogue

Forty narrated, 3Blue1Brown-style explainer videos, each about a result in [github.com/openai/math](https://github.com/openai/math). That repository is the October 2026 release of 722 manuscripts in 372 result families, produced by an unreleased OpenAI model.

**Watch:** download the videos (1080p MP4 + `.srt` subtitles) from the [latest release](https://github.com/dimenwarper/oai-math-vids/releases/latest). Together they run 2 h 56 min, about 3.5–5 minutes each.

> **Please read before sharing.**
> - This project is unofficial and not affiliated with OpenAI or with 3Blue1Brown/Grant Sanderson. "3Blue1Brown-style" describes the visual style (it uses [Manim](https://www.manim.community/), the community fork of his animation engine).
> - The videos explain **claims** from manuscripts that have not been peer reviewed. Each video ends with a card saying whether the main theorem is formalized in Lean, according to the catalogue's own Lean docs. Several are only partly formalized or not formalized at all, and the narration says exactly what is covered.
> - The videos were written, animated and checked by AI agents (Claude), with each one's frames, Lean status and key claims reviewed in a supervising session. They have not been reviewed by mathematicians, and the narration is synthetic speech that hasn't been proofread by ear. Errors are possible. Please open an issue if you find one.

## How they are made

Each video is a single Python file rendered with Manim Community Edition:

- **Narration:** [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), a free open-weight text-to-speech model that runs locally, so making a video costs nothing beyond the time to write it.
- **Sync:** word-level bookmarks in the script keep animations in step with the narration.
- **Data:** numerics (zeta zeros, Gaussian primes, billiard trajectories, eigenfunctions, ...) are computed by small scripts in `videos/data/`.

```
videos/vNN_*.py        one scene per video (narration inline)
videos/data/           make_vNN.py -> vNN.npz precomputed data
common/vo.py           narration: Kokoro TTS, caching, bookmarks, subtitles
common/style.py        palette, title card, closing status card
render.sh              render a video (low = draft, high = 1080p30 into out/)
sheet.sh               contact sheet of frames, for visual QA
pdftxt.py              extract text from the catalogue PDFs
setup.sh               one-time setup (Python env, TinyTeX, clone of openai/math)
docs/making-more.md    how to add videos, including the brief used for parallel agents
```

## Quick start

You need [uv](https://docs.astral.sh/uv/), ffmpeg, git and curl. Tested on macOS (Apple silicon); Linux should work.

```bash
git clone https://github.com/dimenwarper/oai-math-vids.git && cd oai-math-vids
./setup.sh                                   # Python 3.12 env, TinyTeX (no sudo), clone of openai/math
./render.sh videos/v08_thompson_f.py low     # ~1 min draft; the first run downloads the voice model
./render.sh videos/v08_thompson_f.py high    # 1080p30 -> out/v08_thompson_f.mp4 (+ .srt)
```

## Making more

To make more, see [docs/making-more.md](docs/making-more.md). It covers:

- choosing a result and checking its Lean scope;
- the anatomy of a scene;
- the draft → contact sheet → fix → final loop;
- the full brief used to have six AI agents make 30 videos in parallel (about 87k tokens per video), plus a list of good candidates not yet done.
